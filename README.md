# DemoBlaze Manual Testing Project

## Project Overview

DemoBlaze is an e-commerce web application used for practicing
manual software testing.

## Testing Scope

The project covers functional and non-functional test scenarios
for major e-commerce functionalities.

## Modules Tested

- Home Page
- Registration
- Login
- Logout
- Product Categories
- Product Details
- Shopping Cart
- Checkout
- Contact
- About Us

## Testing Types

- Functional Testing
- Positive Testing
- Negative Testing
- UI Testing
- Validation Testing
- Boundary Value Testing
- Exploratory Testing
- End-to-End Testing

## Test Cases

A total of **275 test cases** were designed and executed.

## Defect Management

Defects were documented with:

- Defect ID
- Defect Description
- Expected Result
- Actual Result
- Severity
- Priority
- Status
